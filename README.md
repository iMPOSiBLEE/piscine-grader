# piscine-grader v3

ตัวตรวจ Piscine 42: **Shell00–01, C00–C13** · ภาษาไทย / English

## ติดตั้ง (ครั้งเดียว ไม่ต้องใช้ sudo)
```bash
git clone https://github.com/iMPOSiBLEE/piscine-grader.git ~/piscine-grader
bash ~/piscine-grader/install.sh
```
ปิด Terminal แล้วเปิดใหม่ (อัปเดตทีหลังใช้ `grade update`)

## ใช้
```bash
grade                       # เมนู: ตรวจงานฉัน / งานเพื่อน / ตั้งค่าภาษา
grade C03 ~/c03             # ตรวจเร็ว
grade C03 git@vogsphere...  # clone งานเพื่อนแล้วตรวจ
```
(`grader` ใช้แทน `grade` ได้)
