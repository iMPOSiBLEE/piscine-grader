# piscine-grader

ตัวตรวจ C Piscine 42 (C00–C09) บอกละเอียดว่าผิดตรงไหน พร้อมหน้าเว็บและโหมดแก้อัตโนมัติ

## ติดตั้ง (ครั้งเดียว ไม่ต้องใช้ sudo)
```bash
git clone https://github.com/iMPOSiBLEE/piscine-grader.git ~/piscine-grader
bash ~/piscine-grader/install.sh
```
ปิด Terminal แล้วเปิดใหม่

## ใช้
```bash
grade                                      # เปิดเมนู เลือกด้วยลูกศร ↑↓
grade C03 ~/c03                            # ตรวจเร็ว ไม่ผ่านเมนู
grade C03 git@vogsphere.42bangkok.com:...  # clone งานเพื่อนแล้วตรวจ
grade C03 ~/c03 --no-web                   # ไม่เปิดหน้าเว็บ
grade update                               # อัปเดตตัวตรวจ
```
(`grader` ใช้แทน `grade` ได้)

## บอกอะไรบ้าง
| | |
|---|---|
| 📁 ไฟล์ | ชื่อไฟล์/โฟลเดอร์ผิด (บอกตัวอักษรที่ผิด), ไฟล์ขาด, ไฟล์เกิน |
| 🚫 กฎ | ไม่มี 42 header, มี main, ใช้ฟังก์ชันต้องห้าม (บอกบรรทัด) |
| 📏 Norm | ทุก error ของ norminette พร้อมคำอธิบายภาษาไทยและวิธีแก้ |
| 🔧 คอมไพล์ | ลืม `;` ลืม `,` ไม่ include ตัวแปรซ้ำ ฯลฯ พร้อมเลขบรรทัด |
| 🧠 ผลลัพธ์ | เคสที่ผิด ควรได้/ได้จริง + คำใบ้สาเหตุที่พบบ่อย |

## หน้าเว็บ
- โค้ดแบบ editor บรรทัดที่ผิดมีแถบแดงและคำอธิบายใต้บรรทัด
- กด **Tab** สลับ: โค้ดเดิม → แบบที่แก้แล้ว (บรรทัดเขียว) / คำใบ้ → เฉลย
- ↑ ↓ เปลี่ยนข้อ

## แก้อัตโนมัติ (เฉพาะงานตัวเอง)
แก้ชื่อไฟล์, ลบไฟล์ขยะ, ใส่ header, ลบ main, Tab/Space/ย่อหน้า, `;` `,` และอื่น ๆ
แสดงสิ่งที่จะเปลี่ยนแล้วถาม y/n ก่อนทุกครั้ง ไฟล์เดิมสำรองไว้ที่ `~/grade_backups/` และ**ไม่แก้งานเพื่อน**
ข้อที่ผิด logic ต้องแก้เอง (ดูคำใบ้/เฉลยในหน้าเว็บ)

ตัวตรวจช่วยดูผลเท่านั้น ตอน evaluate ยังต้องอ่านโค้ดกับเพื่อนตามใบประเมิน
